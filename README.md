# GlowTab — App Play Mode × Web · Prototype V1 (2026-11-16)

Open through a local server (audio is fetched and decoded, so `file://` will not play):

    cd "GlowTab Play + Web Prototype" && python3 -m http.server 8884
    # http://localhost:8884   (?view=app | web | both, &song=LJS001 | ART001 | VT001)

- `index.html` — layout, styles, design notes (Thai). Dark / Light theme = CSS tokens at the top (`:root` and `:root[data-theme=light]`), switch in the top bar, `?theme=light`; Hero Mode, toasts and covers stay dark; the sheet's glyph colours are `AT_THEME` in `tab.js`
- `library.js` — Official Tabs browse per the category spec of 2026-11-23 (`../2026-11-23_Official_Tabs_Categories_Metadata_Spec.md`): shelves Signature · Backing Track · Fingerstyle · Classics + starter shelf ordered by the user's level, filter panel with live counts (Style, Scale, Key, play style, tuning, level, Free/PRO, audio), Backing Track detail (ฝึก Lick / ด้นสด), "coming soon" state. Catalogue = 29 real items (3 playable) + 1,210 placeholders. Also My Library folders, mirroring glowtab.litejam.com/library
- `hero.js` — Hero Mode ("Litejam Hero"): note-highway view of the same song on the same audio clock, layout after jamhero.litejam.com; `?song=VT001&hero=1` opens it directly
- `guitar3d.js` — 3D guitar in Hero Mode: the LiteJam 3D guitar module (`vendor/guitar3d/`, byte-identical copy of `litejam-3d-guitar-module`; three.js 0.180.0 in `vendor/three/`, resolved by the import map in `index.html`) above the note highway. Tab-only (fingerstyle) songs use the acoustic A1, the rest RGB24; models in `assets/guitars/` must be served at `/assets/guitars/…` and must not be re-exported or compressed. Loaded on first entry to Hero Mode, disposed on leaving it. The whole guitar is fitted to its box and re-fitted on resize (right-aligned, body in the tall right part); four camera presets under the guitar (Full / Neck / 3/4 / Player, `G3_VIEWS`), a `3D` button to switch the model off and on, and the model mirrors when the string order is flipped; drag = free rotation, Shift-drag / right button = roll, wheel = zoom, double click = reset. `E→e` button in Hero Mode flips the string order on the board (`HFLIP` in `hero.js`)
- `tab.js` — the tab surface, drawn by alphaTab 1.6.3 (`vendor/alphatab/`, same library and version as glowtab.litejam.com) from `data/gp/<id>.gp`; alphaTab's player is off, the audio clock drives our own playhead. Bar loop: A / B buttons, hold-and-drag on the score, draggable loop handles
- `app.js` — shared state, audio engine, LED fretboard canvas, App and Web views
- `data/songs.js`, `media/` — generated by `tools/build_media.py <download_dir> --audio --check`
  (raw WAV/GP sources stay in Drive / Dropbox; see the docstring for file names)

## Cover art for Classics (2026-11-23)

`tools/make_art.py` draws the cover and the Hero Mode backdrop of a Classics song from one public-domain portrait
(`tools/art_src/`, source and credit in the script). LJS001 has three covers: `cover.jpg` Neon Duotone (default),
`cover_b.jpg` Pop Poster, `cover_c.jpg` Old Master — switch with `?art=a|b|c`. `hero.jpg` is the backdrop (no lettering).
`COVER[id].img` / `.hero` in `app.js` point at them. Key content stays inside the middle 800 px square because cards crop.

## Ranked (game mode in Hero Mode)

Some Official Tabs (`GAME_SONGS` in `game.js`: LJS001, ART001, VT001) can be played for a score. Hero Mode › READY has a Jam / Ranked switch; the home page has a "Ranked ประจำสัปดาห์" shelf.

- `detect.js` — note detection and judging, no DOM (YIN pitch tracker + a tone-rise test against neighbouring semitones). Runs in the browser and in node.
- `game.js` — microphone input, the demo bot, runs, coins, leaderboard, shop, panels. Leaderboard, wallet and shop are mock data in `localStorage['gt-game']`.
- `node tools/test_detect.js [songId] [case,case]` — synthesises whole-song performances (perfect, human, every 2nd note, wrong pitch, silence) and prints what the detector judged. About 20 s per song.
- Demo bot ("บอทมือโปร" / "บอทมือกลาง") plays the tab through the same detector, for reviewing without a guitar. The tab must be visible: a background tab is throttled and drops notes.
- A ranked run is the whole song at 100 % with no pause, seek or loop; anything else is a practice score.

Spec: `../2026-11-23_GlowTab_Ranked_Game_Mode_Spec.md`. Not tested with a real guitar through a real microphone yet.

### Practice › ตรวจโน้ต (note check, no score)

The "ตรวจโน้ต" toggle in the Practice docks runs the same detector on any song, at any speed, loops included, and only says right or wrong: the beat turns green or red on the tab (`atMark` in `tab.js`), the LED preview dot follows, and a small readout shows the note the microphone hears. No score, combo, coins or leaderboard. Marks stay until the note is judged again or the player seeks. `?bot=pro` or `?bot=mid` makes the toggle use the demo bot instead of the microphone.

### Practice › Hold-On (wait for the right note)

The "Hold-On" toggle (turns note check on too) stops the song on a note until it is heard: played in time the music never stops; otherwise the playhead freezes on the note 0.12 s after its beat, keeps listening, and carries on from that note. Green = right in time, orange = right after waiting, red = skipped with "ข้ามโน้ต". Play / Pause while waiting really pauses. `gholdFrame` in `game.js`; the detector runs on the audio clock there because song time stands still.
